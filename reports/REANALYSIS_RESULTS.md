# Spike-Based Reanalysis of the 28-Specimen Optotagging Cohort

**Companion to:** `reports/ANALYSIS_REPORT.md`, which this document executes (its Sections 5 and 6).  
**Data:** all 28 Allen Visual Coding Neuropixels sessions in `results/cohort/full_28_specimen_manifest.csv`, downloaded from the public S3 bucket and reduced to spike-level records. **19,005 units** passed the Allen default QC (isi_violations < 0.5, amplitude_cutoff < 0.1, presence_ratio > 0.9, quality = good): 8 Pvalb, 12 Sst and 8 Vip × Ai32 mice. All 18,316 units of the original table are included. The extra 689 (3.6%) pass the same documented filter but were absent from the original table, and the original pipeline does not record why.  
**Rule:** every number below is computed from spike times in the NWB files. Simulation is used only to validate estimators (Section 1).

### Reproduce

```bash
python scripts/reanalysis/00_validate_estimators.py   # estimator calibration (~4 min)
python scripts/reanalysis/01_extract_cohort.py        # download -> extract -> delete, 28 sessions (~60 min, ~28 MB/s)
python scripts/reanalysis/02_unit_inference.py        # per-unit inference (~12 min, 4 cores)
python scripts/reanalysis/03_population_analysis.py   # population and animal-level statistics (~10 min)
python scripts/reanalysis/04_figures.py               # figures R1-R6
```

Code: `src/reanalysis/extract_nwb.py`, `src/reanalysis/inference.py`. Tables: `results/reanalysis/tables/`. Headline numbers: `results/reanalysis/summary.json`. Figures: `results/reanalysis/figures/`. The intermediate spike records (`data/derived/`, about 1 GB) are git-ignored and are regenerated by step 01.

## 1. Estimator validation (simulation with known truth)

Simulated units used the real trial structure (45 trials, [−480, −20) ms baseline, [+1, +9) ms window) and spontaneous rates of 1–60 Hz (`results/reanalysis/tables/estimator_validation.csv`).

* **Exact conditional test.** The null false-positive rate is 2.0–3.0% at nominal 5% (conservative because counts are discrete). Power at ρ = 0.3 is 1.00 at 1–5 Hz, 0.98 at 20 Hz and 0.83 at 60 Hz.
* **SALT port (Kvitsiani et al., 2013).** Null false-positive rate 0–1%. Power at ρ = 0.3 drops to 0.31 at 60 Hz: SALT is weak for high-rate units.
* **First-spike latency model (report Sec. 5.1).**
  * ρ̂ bias ≤ 0.013 in every condition. The **naive reliability is biased upwards by +0.10 to +0.16 at 30 Hz**, which is the chance contamination the model removes.
  * δ̂ bias ≤ 0.04 ms.
  * 95% CI coverage is 0.88–0.95 for ρ ≥ 0.5 but only 0.74–0.89 for weak responses (ρ = 0.2), where the Wald intervals are optimistic. CIs for weak units should be treated as approximate.
* **Local FDR with a sham-window empirical null (Sec. 5.6).** π₀ is estimated at 0.962 (truth 0.97). The selection lfdr < 0.05 has a **realised FDR of 0.000**, estimated FDR 0.002, and sensitivity 0.86. Units with lfdr ∈ [0.8, 1] are null 99.9% of the time.
* **Multinomial mixture (Sec. 5.7).** BIC recovers the planted k = 4, ARI 0.83.
* **Jitter-corrected CCG test (Stark & Abeles, 2009).** False-positive rate 0.5% (excitation) and 0% (inhibition) at p < 0.01; power 1.0 for a 50% inhibition at 1–4 ms.

## 2. Which units are light-activated? (Fig. R1)

**Statistic.** For each unit, the exact conditional (binomial) test compares the [+1, +9) ms count with the same trials' [−480, −20) ms baseline. That baseline is 0.46 s per trial, so the median baseline exposure is 20.7 s rather than the original 0.675 s. The mid-p one-sided p-value is converted to z. The **empirical null** is the same statistic computed in 10 non-overlapping 8-ms sham windows inside the pre-stimulus period of the same trials. The sham false-positive rate at p < 0.05 is 4.0%, so the null is calibrated.

**Result.** π₀ = 1.0, the null proportion at the precision available. 375 units have lfdr < 0.05. Of these, 25 are **light-onset artifacts**: fitted latency at the window edge (δ̂ < 1.5 ms), jitter at the 0.1-ms bound, and locations that surface light cannot reach (LGd, LGv, CA3, DG, PPT, SCiw, NOT). Ten come from a single Vip session (819701982) and appear simultaneously across regions. The repository's artifact rule (median raw latency < 1.2 ms and SD < 0.1 ms) cannot catch them, because spontaneous first spikes pull the raw median towards 5 ms. After excluding them, **350 units are light-activated** (estimated FDR 0.3%): 79% in visual cortex and 17% in CA1 and other hippocampal areas.

**Method comparison** (`method_comparison.csv`, `method_overlap_patterns.csv`).

*Update (calibration rebuild):* ZETA is now recomputed with a fixed per-unit seed. zetapy resamples with NumPy's global RNG, and unseeded p-values moved by up to 0.10 between runs. The ZETA rows below are the seeded values. The two rows for the original synthetic-latency "SALT"/"ZETA" are historical. Those columns are now in `archive/` and are no longer read by the pipeline, so they no longer appear in `method_comparison.csv`. Independent seeded ZETA runs in `scripts/calibration/04_criteria_calibration.py` give 17 and 1,085 positives, which shows the Monte Carlo spread of zetapy p-values near the threshold.

| Method (raw spikes) | Positives | ∩ light-activated | Jaccard |
|---|---|---|---|
| lfdr < 0.05 (this work) | 350 | 350 | 1.00 |
| exact test, BH q < 0.05 | 396 | 350 | 0.88 |
| SALT port, p < 0.01 | 454 | 331 | 0.70 |
| SALT port, BH q < 0.05 | 381 | 310 | 0.74 |
| ZETA (zetapy), window [1, 9) ms, positive, BH | 15 | 13 | 0.04 |
| ZETA (zetapy), window [1, 51) ms, any sign, BH | 1,091 | 328 | 0.29 |
| original heuristic label | 261 | 243 | 0.66 |
| original "SALT" (synthetic latencies; now in `archive/`) | 711 | 40 | 0.04 |
| original "ZETA" (synthetic latencies; now in `archive/`) | 2,139 | 204 | 0.09 |

Interpretation:
* **Correct implementations largely agree.** The real disagreements are interpretable:
  * SALT adds units whose latency distribution changes without a large rate change, and loses high-rate units (Sec. 1).
  * ZETA over [1, 51) ms is a general *responsiveness* test. It flags 1,091 units, mostly network-modulated (excitation or suppression), and gives zero sham discoveries at BH q < 0.05.
* **ZETA confined to the direct window has almost no power** (20 units). ZETA measures non-uniformity of spike timing *within* its window, so a window filled by the response leaves nothing to detect. This is a practical caveat for anyone applying ZETA to optotagging.
* **The original SALT/ZETA columns are essentially unrelated to light activation** (Jaccard 0.04 and 0.09), which confirms that the "method disagreement" result came from the synthetic inputs.
* **The operational heuristic is specific but insensitive.** 243/261 of its units are confirmed, and 17 of its 18 non-confirmed units still have p < 0.05 but lfdr ≥ 0.05. It misses 107 light-activated units, mostly through the reliability ≥ 0.30 and modulation > 2 thresholds.

## 3. Are they real, and are they the targeted cells? (Fig. R2)

* **Independent replication.** The 5-ms pulses are separate trials. 92% of light-activated units are significant on them (one-sided p < 0.05), against 3.5% of null units (lfdr > 0.5). Activation probability replicates (Spearman 0.84), and so does latency (0.75; median δ̂ is 0.38 ms *shorter* for 5-ms pulses).
* **Waveform identity.** Narrow spikes (trough-to-peak < 0.4 ms) identify fast-spiking PV interneurons:
  * Pvalb: 82% of light-activated units are narrow vs 21% of other units (OR 17.8).
  * Sst: 51% vs 21% (OR 4.0), consistent with the known narrow-spiking subset of SST cells.
  * Vip: 17% vs 21% (no enrichment), as expected for VIP cells.

  This is an independent biological check that the original analysis never ran, and it supports the evidence score.
* **Latency model** (`driven_unit_latency_characterisation.csv`):

  | Cre line | n | median ρ̂ | median δ̂ (ms) | IQR (ms) | median σ̂ (ms) |
  |---|---|---|---|---|---|
  | Pvalb | 181 | 0.51 | 4.5 | 3.4–5.6 | 2.0 |
  | Sst | 146 | 0.45 | 5.9 | 4.6–7.2 | 1.4 |
  | Vip | 22 | 0.36 | 3.3 | 2.3–5.8 | 1.2 |

  Only 24% satisfy a strict "direct-like" profile (δ̂ < 5 ms and σ̂ < 1.5 ms). The rest have later or more jittered responses, so many light-activated units may be activated synaptically rather than through their own ChR2. **Light activation ≠ direct tagging**, and the two-dimensional (δ̂, σ̂) description is more informative than a binary label.
* **Latency criterion specificity.** Among 13,412 null-like units (lfdr > 0.5) that fired at least once in the evoked window, **96.7% have a median latency < 8 ms**, against a theoretical 87.5–100% (report Sec. 5.2). The latency criterion carries essentially no information inside a [1, 9) ms window.

## 4. Yield and suppression by Cre line, animal as replicate (Fig. R3)

* **Light-activated yield** (fraction of units per animal): Pvalb 3.9 ± 1.4%, Sst 1.7 ± 0.5%, Vip 0.46 ± 0.20% (mean ± SEM over animals; permutation of Cre labels across the 28 animals, p = 0.022). Within visual cortex the yields are 7.0%, 2.5% and 0.7%. Four sessions have no light-activated unit, and yield varies widely between animals (ICC 0.035, design effect 25). Any unit-pooled comparison of yields overstates precision about five-fold (√25).
* **Suppression** (exact lower-tail test, 20–50 or 50–200 ms vs baseline, BH q < 0.05, excluding light-activated units):

  | Region | Pvalb | Sst | Vip |
  |---|---|---|---|
  | visual cortex | 41 ± 4% | 36 ± 5% | 20 ± 2% |
  | thalamus | 29% | 28% | 23% |
  | hippocampal formation | 4% | 9% | 3% |

  In visual cortex the Cre-line difference is significant at the animal level (p = 0.024). PV and SST activation silence about twice as many cortical units as VIP activation, consistent with their inhibitory output. However, **thalamic suppression is similar in all three lines**, so part of the response is not mediated by the opsin-expressing population. Candidates are light reaching the retina (a visual response to the blue flash) or a global state change. Separating these needs an opsin-negative control or a masking light, which this dataset does not contain. That caveat applies to every "network" claim.
* **Detectability matters.** In units with enough baseline spikes to detect silencing (expected 50–200 ms count ≥ 20), suppression rises to 33/29/18%. Suppression prevalence measured in low-rate units is therefore underestimated, not "quiescent".

## 5. Response archetypes (Fig. R4)

A mixture of multinomials over counts in the baseline and five post-pulse windows (1–9, 11–20, 20–50, 50–200, 200–500 ms). The unit's own baseline rate cancels, so clusters capture response *shape*.

* **No discrete number of types.** BIC keeps improving up to k = 16 (by 91,920 for 1 → 2 and still by 3,823 for 15 → 16). The response space is a continuum, and "archetypes" are a descriptive partition, not cell classes.
* At k = 6 the partition is stable (bootstrap ARI 0.89–0.97; at k = 4 only 0.73–0.81):

  | | 1–9 | 11–20 | 20–50 | 50–200 | 200–500 ms | units | PV / SST / VIP share | animal-level Cre q |
  |---|---|---|---|---|---|---|---|---|
  | A0 light-activated, then silenced | 12.9 | 2.4 | 0.21 | 1.05 | 0.94 | 255 | 2.6 / 1.2 / 0.5% | 0.12 |
  | A1 unmodulated | 1.00 | 0.91 | 0.97 | 1.01 | 0.99 | 12,090 | 57 / 62 / 72% | 0.13 |
  | A2 late excitation 50–200 ms | 1.34 | 0.62 | 1.52 | 5.18 | 1.32 | 574 | 3.9 / 2.6 / 2.9% | 0.27 |
  | A3 weak sustained suppression | 0.90 | 0.69 | 0.61 | 0.42 | 0.77 | 2,225 | 10 / 12 / 13% | 0.27 |
  | A4 moderate late excitation | 0.99 | 0.84 | 1.60 | 1.90 | 1.00 | 1,271 | 6.1 / 4.9 / **10.0%** | **0.005** |
  | A5 early deep suppression 11–50 ms | 0.84 | 0.17 | 0.10 | 0.97 | 0.99 | 2,590 | **20 / 18 / 1.7%** | **0.005** |

  (Window columns are rate ÷ baseline.)

  The two Cre-specific profiles are biologically coherent. Brief, deep suppression right after the pulse (A5) is almost absent in VIP sessions, matching direct GABAergic output from PV/SST cells. Moderate delayed excitation (A4) is enriched in VIP sessions, matching disinhibition.

## 6. Dose and pulse trains (Fig. R5)

* **Light levels.** The NWB `level` values form three session-specific sets: {1.0, 2.5, 4.0} (15 sessions), {1.3, 1.7, 2.0} (11) and {0.638, 0.738, 0.82} (2). Their physical units are not stated in the file, so levels are compared by within-session rank. The original pipeline assumed "1.0, 2.5, 4.0 mW calibrated" for every session, so the 8,348 units in the other 13 sessions received empty per-level responses.
* **Activation probability rises with light level** in every line: Δρ̂ (high − low) = +0.45 (PV), +0.45 (SST), +0.30 (VIP), +0.41 overall (24 animals, t = 11.5, p < 10⁻⁸); 92% of units increase. The median ρ̂ is 0.08 / 0.47 / 0.70 at low / mid / high.
* **Latency shortens with light level** in PV (−1.0 ms, high vs low, p = 0.056 across 6 animals) and VIP (−1.1 ms, n.s.), but not in SST (+0.35 ms, n.s.). Overall the effect is −0.42 ± 0.36 ms (n.s.). Shortening with intensity is the expected signature of direct opsin drive; its weakness in SST fits the larger indirect component in Section 3.
* **10-Hz trains (2.5-ms pulses).** Light-activated units fire on 17–26% of pulses (chance 5–10%), flat across the 10 pulses. The animal-level log-ratio pulse 10 vs 1 is −0.16 ± 0.09 (PV), −0.02 ± 0.09 (SST) and +0.07 ± 0.12 (VIP), with no Cre difference (p = 0.34). At this drive there is **no measurable depression or facilitation**. The original cell-type "adaptation" result is not supported. Note that 2.5-ms pulses activate these units much less reliably than 10-ms pulses, so the train data have limited power for any adaptation analysis.

## 7. Depth and connectivity (Fig. R6)

* **Depth.** Among 8,878 visual-cortex units, the probability of light activation falls with depth below the cortical surface (logit −0.19 per 100 µm, SE 0.04, p = 4 × 10⁻⁷, session fixed effects). That matches attenuation of light delivered from the surface. Within light-activated units (mixed model, random intercept per probe, 74 probes), deeper units have *shorter* latency (−0.17 ms per 100 µm, p = 0.001) and smaller jitter (−0.09 ms per 100 µm, p = 0.03). That is the opposite of a "propagation" gradient. It is more consistent with deep-layer cell types or with direct activation of their superficial dendrites, which a shank coordinate cannot separate.
* **Connectivity** from spontaneous epochs (± 30 ms CCGs, Stark–Abeles convolution predictor, bins +0.8 to +4 ms, Bonferroni over bins, p < 0.01):

  | Reference units | Pairs | Short-latency trough (b after a) | Control (b before a) |
  |---|---|---|---|
  | PV-activated | 7,632 | **7.7%** | 2.5% |
  | SST-activated | 7,367 | **3.9%** | 1.7% |
  | VIP-activated | 668 | 1.0% | 1.0% |

  PV troughs fall steeply with vertical distance: 16.7% (≤ 50 µm), 11.1%, 4.1%, 1.6% (200–300 µm). This is the expected footprint of local perisomatic inhibition and the first genuine connectivity result in this repository. Excitatory peaks are *more* common in the anticausal direction for PV reference units (11.3% vs 5.4%), consistent with excitatory input *onto* PV cells.

## 8. Revisiting the original statistical claims

* **Sparse-firing tier.** With spontaneous rates from the long spontaneous epochs, the < 1 Hz tier holds 3,011 units (not 3,867). The Poisson expectation of units with at least one evoked-window spike is 607, against 871 observed (ratio 1.43; light-activated units account for 29). In all other tiers the ratio is 0.94–1.06. The original "44% explained by Poisson" figure, and its 80% conditional probability, should be replaced by these numbers.
* **Threshold instability** is mostly predictable binomial noise. For light-activated units the mean probability that raw reliability falls on the other side of 0.30 on a re-run is 0.05, and 8.9% of units exceed 0.2.
* **Variance decomposition** (`variance_decomposition.csv`):

  | Metric | ICC(1) | F(27, 18977) | Design effect |
  |---|---|---|---|
  | spontaneous rate (log) | 0.017 | 12.4 | 12.2 |
  | log rate ratio (10 ms) | 0.013 | 9.7 | 9.6 |
  | light-activated (0/1) | 0.035 | 25.4 | 24.6 |

  Most variance is within animals, as the original analysis said. But animals differ highly significantly (all p < 10⁻⁴⁰), and the design effects mean that unit-level statistics overstate precision 3–5×. All between-Cre tests above are therefore done at the animal level.

## 9. Limitations

* **Direct tagging is not proven for any unit.** The evidence score measures *light activation*. Direct ChR2 expression needs latency/jitter criteria (Sec. 3), collision tests or histology. The (δ̂, σ̂) map is the honest summary.
* **No raw voltage traces.** The light-evoked vs spontaneous waveform test (Lima et al., 2009) cannot be run from the session NWB, which stores only mean waveforms.
* **Possible visual or non-opsin effects** (Sec. 4) cannot be excluded without an opsin-negative control.
* **Fiber position is unknown**, so depth is a proxy for irradiance. Light-level units differ across sessions.
* **Archetypes are a descriptive partition** of a continuum.
* **Weak-response CIs.** Wald CIs from the latency model under-cover for ρ ≈ 0.2 (coverage 0.74–0.89). Profile-likelihood or bootstrap intervals would be better for weak units.
* **Unit-set discrepancy.** 689 units (3.6%) are present here but were absent from the original table.

## 10. What the manuscript can now say

1. A calibrated evidence score (1 − lfdr with an empirical null from sham windows) identifies 350 light-activated units at an estimated FDR of 0.3%. They replicate on independent trials (92%) and carry the expected waveform signature in Pvalb and Sst mice.
2. The conventional latency criterion is uninformative inside the standard window (96.7% of null units pass), and the reliability threshold carries predictable binomial instability. The heuristic misses about 30% of light-activated units.
3. Most light-activated units are not "direct-like" by latency and jitter. The binary tag conflates direct and synaptic activation.
4. PV and SST activation suppress many more cortical units than VIP activation. A Cre-independent suppression component calls for opsin-negative controls.
5. PV-activated units show distance-dependent monosynaptic-like inhibition in spontaneous activity.
6. No cell-type-specific 10-Hz adaptation is detectable. Light level, not cell type, dominates reliability.

The simulated or hard-coded results listed in `reports/ANALYSIS_REPORT.md` §0 (train adaptation, W1–W5 rules, CCG constants, negative controls, synthetic SALT/ZETA, formula-drawn figure panels) should be replaced by the corresponding sections above.
