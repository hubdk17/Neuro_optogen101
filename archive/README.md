# archive/ — superseded material that was NOT computed from data

**Nothing in this directory is a result.** The numbers, tables, figures and manuscript text here were produced by random-number draws, hand-written rules and hard-coded constants, not by analysing the recorded spike trains. They are kept only so that the history of the project is auditable. **No file in `src/` or `scripts/` uses anything here**, and `tests/test_archive_isolation.py` fails if that changes.

The data-derived analysis that replaces this material is the spike-based pipeline in `src/reanalysis/`, `scripts/reanalysis/` and `scripts/calibration/`, with outputs in `results/reanalysis/` and `results/calibration/` (see the root `README.md`).

Files were moved here with `git mv`, preserving their paths relative to the repository root, so `git log --follow archive/<path>` shows their full history and the move is reversible.

## What each file does instead of analysing data

Line numbers refer to the files as they sit in this directory.

### Analysis scripts

| File | Mechanism | Lines |
|---|---|---|
| `scripts/run_neuroscience_study_stage1_methods.py` | SALT and ZETA are run on **synthetic first-spike latencies** drawn as `rng.normal(loc=median_latency, scale=latency_sd)`, not on spike times. The "method disagreement" results (13-unit consensus, 179 SALT+ZETA-only units) come from these draws. | 109–118 (draw at 116) |
| `scripts/run_neuroscience_study_stage2_phenotypes.py` | The five post-stimulus window rates W1–W5 are **generated by if/else rules** from Cre line and baseline rate, e.g. `w3_rate = 0.35 × baseline` for non-direct PV units and `w4_rate = 0.45 × baseline` for PV/SST units above 2 Hz. "Prolonged Suppression" and the cell-type "fingerprints" are consequences of these rules. | 63–92 |
| `scripts/run_neuroscience_study_stage3_networks.py` | The cross-correlogram "synchrony surge" is **hard-coded**: `baseline_sync = 0.045/0.038/0.031`, `post_stim_sync = 0.182/0.095/0.062`, `lag_shift_ms = 3.2/4.8/8.5`, and the p-value is the string literal `"< 0.0001"`. The four "negative controls" (sham, label permutation, time shift, jitter) are **dictionary literals** with typed-in positive rates. A fallback `early_ba = 0.72` replaces a computed accuracy when data are short. The Cre-line decoding uses W-features that encode Cre line by construction (stage 2). | 166–191; 210–247; 286 |
| `scripts/run_rigorous_neuroscience_reanalysis.py` | 10-Hz train adaptation is **simulated**: `r10 = r1 × rng.normal(0.35, 0.08)` (PV), `rng.normal(0.40, 0.10)` (SST), `rng.normal(1.40, 0.20)` (VIP). The Poisson null uses a wrong exposure (`tau_sec = 75 × 0.010`), and its output is **clipped to 0.79–0.82** to force the reported 80%. When the distance column is missing it is replaced by `|probe_vertical_position − 1500|`. | 68–101; 162; 185; 385 |
| `scripts/run_secondary_stimulation_validation.py` | The 5-ms vs 10-ms latency "invariance" is the 10-ms latency times `np.random.normal(1.01, 0.05)`; the multi-condition evidence "concordance" is the evidence score times `np.random.normal(0.98, 0.04)`. | 143; 156 |
| `scripts/run_controls_and_latency_analysis.py` | The "label-permutation" control draws its null p-values, modulations and latencies from **uniform distributions** (`np.random.uniform(0.01, 1.0)`, …) instead of permuting data. | 133–139 |
| `scripts/update_reports_with_reviewer_fixes.py` | Writes reviewer-response text and tables containing the figures above, typed into markdown strings, and marks them "VERIFIED & RESOLVED". | whole file |

### Manuscript

`manuscript/main.tex` and `manuscript/manuscript_tcbb.tex` were written on top of the material above. Their abstract and results report the simulated adaptation, the rule-generated suppression archetypes, the hard-coded CCG surge, the never-fitted spatial gradient (with a velocity miscalculated by about 13×), and the synthetic SALT/ZETA comparison. The "audit" table at lines 650–663 marks those calculations as **PASS**. That table is self-certification, not verification. **Both files are superseded and must not be used as a basis for submission.** (`manuscript/references.bib` stays outside the archive; several of its entries need correction, see `reports/ANALYSIS_REPORT.md` §1.8.)

### Audit tool

`audit/verify_analysis_report.py` is the script that documented the problems above (`reports/ANALYSIS_REPORT.md`). It reads the archived unit table and is kept with it for provenance.

## Historical note on the superseded "SALT" and "ZETA" columns

When the spike-based reanalysis was first run, the archived method columns were compared with properly computed tests on the same units. The archived "SALT" positives (711 units) overlapped the calibrated light-activated set (350 units) in 40 units, and the archived "ZETA" positives (2,139) in 204, compared with 331 for a faithful SALT port. Those comparison numbers are recorded in `reports/REANALYSIS_RESULTS.md` §2. The live pipeline no longer reads the archived columns.
